# SettleTrace

### AI-powered settlement reconciliation, anomaly detection & investigation

> **Money can move correctly and still fail to reconcile.**
>
> SettleTrace is a financial control platform that traces money across
> payment settlements, bank credits, and ledger records — detects what
> doesn't match, investigates why, and turns the result into an
> explainable, auditable decision.

---
